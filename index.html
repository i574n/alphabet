alphabet

https://i574n.github.io/alphabet

Writing-system tools in Spiral: render markdown documents as books, each with a Korean (hangul) transcription alongside it.

Apps

| App | What it does | | --- | --- | | apps/documents | Walks a source tree of .md files and renders each to HTML, PDF and EPUB with crowbook. It also writes a hangul transcription (.hangul.md) through hangulize, with the spec chosen per document (--hangul-spec, default por-br; English text uses eng), and renders that too. Unchanged files are skipped by content hash against a cache dir. --transcribe-only keeps only the transcribed lines, and --filter limits the run to matching paths. vault publishes with it. | | apps/hangul | Hangul in Spiral: syllable composition and decomposition, jamo and compatibility letters, hanja-to-hangul readings over a full hanja table, particle selection, stroke counts, and CP949 decoding and encoding with typed failures. |

Getting started

git clone https://github.com/i574n/alphabet.git
cd alphabet
pwsh scripts/workflow.ps1

scripts/init.ps1 clones spiral next to this repository and runs its toolchain setup, then installs pandoc, crowbook, tectonic, the NanumGothicCoding font and hangulize.
